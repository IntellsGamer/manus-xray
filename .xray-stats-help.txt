usage: xray api statsquery [--server=127.0.0.1:8080] [-pattern '']

Query statistics from Xray.

Arguments:

	-s, -server <server:port>
		The API server address. Default 127.0.0.1:8080

	-t, -timeout <seconds>
		Timeout in seconds for calling API. Default 3

	-pattern
		Filter pattern for the statistics query.

	-reset
		Reset the counter after fetching their values. Default false

Example:

	xray api statsquery --server=127.0.0.1:8080 -pattern "counter_"
